# VELORA – Wear Your Confidence

A modern and elegant fashion e-commerce website built using the MERN stack.

## About VELORA

VELORA is a fashion shopping platform designed to provide customers with a smooth and enjoyable online shopping experience.

Discover modern fashion, explore collections, and shop your favourite styles in one place.

## Features

- Modern and responsive user interface
- Browse fashion collections
- Search and filter products
- Product details and variations
- Shopping cart
- Wishlist
- User authentication
- Secure checkout and payments
- Order management
- Admin dashboard

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shreekanya-n/velora.git
```

### 2. Navigate to the frontend folder

```bash
cd velora/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
